# Changelog

Histórico de mudanças no repositório.

## [1.0.0] - 2026-04-28

- Adicionados guias iniciais (ai-agent.md, workflow.md, faq.md)
- Criados templates para Java Spring, Node.js, FastAPI, Angular
- README inicial com conceitos fundamentais
- Adicionada pasta docs/ com getting-started.md, skills.md, instructions.md, contributing.md
- Novos guias: troubleshooting.md, examples.md, advanced-workflow.md
- CHANGELOG.md para rastrear atualizações
- Diagramas Mermaid integrados em guias
- Adicionados templates alternativos em `templates/alternatives/`:
  - `skills.json`: Skills estruturadas em JSON para parsing fácil.
  - `skills.yaml`: Skills legíveis em YAML para manutenção.
  - `instructions.xml`: Instructions validáveis em XML com schemas.
- Atualizado README com seção de formatos alternativos.

Nota: Este changelog será atualizado com futuras releases.
