# Changelog

Histórico de mudanças no repositório.

## [1.0.0] - 2026-04-28

- Adicionados guias iniciais (ai-agent.md, workflow.md, faq.md)
- Criados templates para Java Spring, Node.js, FastAPI, Angular
- README inicial com conceitos fundamentais
- Adicionada pasta docs/ com getting-started.md, skills.md, instructions.md, contributing.md
- Novos guias: troubleshooting.md, examples.md, advanced-workflow.md
- CHANGELOG.md para rastrear atualizações
- Diagramas Mermaid integrados em guias
- Adicionados templates alternativos em `templates/alternatives/`:
  - `skills.json`: Skills estruturadas em JSON para parsing fácil.
  - `skills.yaml`: Skills legíveis em YAML para manutenção.
  - `instructions.xml`: Instructions validáveis em XML com schemas.
- Atualizado README com seção de formatos alternativos.

## [1.0.1] - 2026-05-01

- Adiciona starter packs arquiteturais para orientar contexto de agentes:
  - MVC + DDD
  - Hexagonal
  - Modular Monolith
  - EDA + CQRS
- Atualiza templates e guias para expor contextos de arquitetura mais amplos.

## [1.0.2] - 2026-05-03

- Adiciona `templates/python/` com índice e 4 starter packs Python:
  - API em camadas
  - Django apps
  - Pacotes por domínio
  - Async workers e filas
- Atualizado `README.md`, `guides/ai-agent.md` e `docs/getting-started.md` para apontar para `templates/python/README.md`
- Mantido atalho rápido `templates/python-fastapi/agent-instructions.md`

## [1.0.3] - 2026-05-04

- Adicionado índice de starter packs `templates/javascript-node/README.md`
- Criados starter packs JavaScript Node para arquiteturas comuns:
  - API em camadas
  - Pacotes por domínio
  - Serverless functions
  - Async workers e filas
- Atualizado `README.md`, `guides/ai-agent.md` e `docs/getting-started.md` para apontar ao novo índice Node.js

## [1.0.4] - 2026-05-04

- Adicionado índice de starter packs `templates/frontend/README.md`
- Criados starter packs Front-end para arquiteturas comuns:
  - Microfrontends
  - SPA Component-Driven
  - Design System
  - Jamstack/SSR/SSG
- Atualizado `README.md`, `guides/ai-agent.md` e `docs/getting-started.md` para apontar ao novo índice front-end

Nota: Este changelog será atualizado com futuras releases.
