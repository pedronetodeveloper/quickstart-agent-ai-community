# Guia de Contribuição

Bem-vindo! Este projeto valoriza contribuições da comunidade. Leia este guia para contribuir efetivamente.

## Como Contribuir

1. **Fork o Repositório**: Crie uma cópia no seu GitHub
2. **Clone Localmente**: `git clone https://github.com/pedronetodeveloper/quickstart-agent-ai-community.git`
3. **Crie uma Branch**: `git checkout -b feature/nova-ideia`
4. **Faça Mudanças**: Adicione/edit arquivos .md ou templates
6. **Commit e Push**: Use mensagens descritivas
7. **Abra um PR**: Descreva mudanças no GitHub

## Padrões de Codificação

- **Markdown**: Use títulos hierárquicos, listas e links relativos
- **Idioma**: Português brasileiro para consistência
- **Estrutura**: Mantenha pastas organizadas (docs/, guides/, templates/)
- **Commits**: "Adiciona guia de troubleshooting" (não "fix")

## Sugestões de Contribuição

- Novos templates para tecnologias
- Guias adicionais
- Correções de tradução ou erros
- Exemplos práticos

## Reportando Issues

Use issues para bugs ou sugestões. Inclua:
- Descrição clara
- Passos para reproduzir
- Ambiente (VS Code, Copilot versão)

Obrigado por contribuir para a comunidade!
