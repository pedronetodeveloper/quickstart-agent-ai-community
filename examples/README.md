# Exemplos de Agentes

Esta pasta contém exemplos práticos de agentes com `.instructions.md` e `skills.json` prontos para uso.

## Exemplos incluídos

- `python-fastapi/`
  - Agent para backend Python com FastAPI
  - Skills para criação de endpoints e testes com pytest
- `java-spring-boot/`
  - Agent para backend Java Spring Boot
  - Skills para controllers REST e testes JUnit
- `node-api/`
  - Agent para API Node.js ESM
  - Skills para validação Zod e testes com Vitest/Jest
- `frontend-react/`
  - Agent para front-end React
  - Skills para componentes acessíveis e testes com React Testing Library

## Uso

Copie o exemplo desejado para a raiz do projeto ou para uma pasta de trabalho e use o GitHub Copilot Chat com esses arquivos.
