# Perguntas Frequentes (FAQ)

## O que é o Copilot Agents Quickstart?

O Copilot Agents Quickstart é um repositório projetado para ajudar usuários a começarem com agentes de IA personalizados para o GitHub Copilot. Ele fornece templates e guias para desenvolver skills e contribuir para a comunidade.

## Como começar com os agentes do Copilot?

Para começar, consulte o guia [Primeiros Passos](../docs/getting-started.md), que fornece instruções passo a passo para configurar os agentes e sua configuração inicial.

## Quais skills posso desenvolver com os agentes?

Você pode desenvolver várias skills com os agentes. Para uma lista abrangente de skills e suas descrições, consulte o documento [Skills](../docs/skills.md).

## Como posso contribuir para este projeto?

Aceitamos contribuições! Leia o guia [Contribuição](../docs/contributing.md) para informações sobre como enviar issues, pull requests e aderir aos nossos padrões de codificação.

## Onde posso encontrar instruções detalhadas sobre o uso dos agentes?

Instruções detalhadas estão disponíveis no documento [Instruções](../docs/instructions.md), que cobre comandos, configurações e melhores práticas para usar os agentes de forma eficaz.

## O que devo fazer se encontrar um problema?

Se encontrar algum problema, consulte o [FAQ](#) para problemas comuns e soluções. Se seu problema não estiver listado, sinta-se à vontade para abrir um novo issue no repositório.

## Como posso personalizar os agentes?

Opções de personalização estão descritas no documento [Instruções](../docs/instructions.md). Você pode modificar configurações e comandos para adaptar os agentes às suas necessidades.

## Há um template para documentar novas skills?

Sim, fornecemos um template de documentação de skills localizado no diretório [templates](../docs/templates/skill-template.md). Isso garante consistência em toda a documentação de skills.

## Quem posso contatar para suporte?

Para suporte, você pode entrar em contato através da seção de issues do repositório ou contatar os mantenedores diretamente se suas informações estiverem fornecidas no README.md.
