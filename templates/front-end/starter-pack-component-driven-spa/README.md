# Starter Pack Front-end — SPA Component-Driven

Pack para SPA moderna com componentes reutilizáveis, feature modules, roteamento e estado.

## Quando usar

- Aplicação front-end composta por domínios de negócio.
- Alto uso de componentes reutilizáveis e lazy loading.
- Frameworks como React, Vue, Angular ou Svelte.

## O que não é

- Não é arquitetura distribuída; é SPA monolítica bem modularizada.
- Não é para projetos sem necessidade de roteamento complexo.
