# Starter Pack Front-end — Design System

Pack para biblioteca de componentes, tokens e design system compartilhado.

## Quando usar

- Consistência visual e UI entre múltiplas aplicações.
- Time quer publicar pacote de componentes.
- Versionamento e documentação de design system.

## O que não é

- Não é aplicação completa; é biblioteca de UI.
- Não é para projetos sem necessidade de compartilhamento.
