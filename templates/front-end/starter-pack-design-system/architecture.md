# Arquitetura — Design System

- `tokens/`: cores, tipografia, espaçamento.
- `components/`: componentes base e compostos.
- `docs/`: documentação e stories.
- `build/`: configurações de publicação.

## Princípios

- Tokens como fonte única de verdade.
- Componentes compostáveis e acessíveis.
- Versionamento para mudanças breaking.

## Anti-padrões

- Componentes hardcoded sem tokens.
- Falta de documentação ou testes.
- Mudanças sem versionamento.
