# Starter Pack Front-end — Jamstack/SSR/SSG

Pack para Jamstack, SSR e SSG com foco em performance, cache e SEO.

## Quando usar

- Sites de marketing, e-commerces, docs.
- Alto desempenho, SEO e pré-renderização.
- Conteúdo estático e híbrido.

## O que não é

- Não é SPA interativa pesada; é otimizada para conteúdo.
- Não é para aplicações com muito estado dinâmico.
