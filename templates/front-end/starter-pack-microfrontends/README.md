# Starter Pack Front-end — Microfrontends

Pack para arquitetura de microfrontends, onde múltiplos times entregam front-end independentemente com integração gradual.

## Quando usar

- Múltiplos times trabalhando em partes diferentes do front-end.
- Necessidade de deploy independente e integração gradual.
- Orquestração de shell, federated modules ou iframes.

## O que não é

- Não é SPA monolítica; é arquitetura distribuída para front-end.
- Não é para projetos pequenos sem necessidade de isolamento de times.
