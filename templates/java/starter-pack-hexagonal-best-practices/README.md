# Starter Pack Java (Hexagonal / Ports and Adapters)

Pack focado em isolamento de dominio, com framework tratado como detalhe de adaptador.

## Quando usar

- dominio complexo;
- multiplas integracoes externas;
- necessidade alta de testabilidade e evolucao.

## Principio central

O dominio nao conhece framework, banco, fila ou protocolo.
