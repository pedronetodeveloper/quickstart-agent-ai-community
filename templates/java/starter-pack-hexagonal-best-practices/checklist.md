# Checklist de Qualidade (Hexagonal)

- Dominio livre de framework/infra?
- Portas modeladas por linguagem de negocio?
- Caso de uso isolado de detalhes tecnicos?
- Adaptadores apenas traduzem entrada/saida?
- Direcao de dependencia para dentro respeitada?
- Testes unitarios de dominio/aplicacao criados?
- Testes de integracao dos adaptadores criados?
