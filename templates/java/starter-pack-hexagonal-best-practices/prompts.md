# Prompt Pack (Hexagonal)

## Nova feature

```text
Implemente a feature "<NOME_FEATURE>" com arquitetura hexagonal.
1) modele o dominio;
2) defina porta de entrada;
3) defina portas de saida;
4) implemente caso de uso;
5) implemente adaptadores;
6) adicione testes unitarios e de integracao.
```

## Review arquitetural

```text
Revise com foco em hexagonal:
- regras no dominio/aplicacao;
- dependencias apontando para dentro;
- adaptadores sem logica de negocio.
Classifique por severidade e sugira correcoes.
```

## Refatoracao

```text
Refatore este fluxo para hexagonal, extraindo portas e reduzindo acoplamento a infraestrutura.
```
