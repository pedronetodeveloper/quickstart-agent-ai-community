# Skills Prioritarias do Agente (Hexagonal)

1. Modelar dominio puro e independente.
2. Definir portas de entrada por caso de uso.
3. Definir portas de saida por necessidade de negocio.
4. Implementar casos de uso na aplicacao.
5. Criar adaptadores de entrada e saida enxutos.
6. Aplicar inversao de dependencia corretamente.
7. Escrever testes unitarios com doubles de portas.
8. Escrever testes de integracao para adaptadores.
