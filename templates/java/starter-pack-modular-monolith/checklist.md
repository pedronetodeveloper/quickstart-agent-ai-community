# Checklist de Qualidade (Modular Monolith)

- Modulo dono do caso de uso esta correto?
- API interna do modulo esta explicita?
- Nao ha acesso a internals de outros modulos?
- Nao ha dependencia ciclica?
- Integracoes entre modulos estao testadas?
- Testes unitarios do modulo criados?
- Teste de integracao do fluxo principal criado?
