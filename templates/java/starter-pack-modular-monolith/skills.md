# Skills Prioritarias do Agente (Modular Monolith)

1. Identificar modulos de negocio coesos.
2. Definir API interna por modulo.
3. Impedir acesso direto a internals de outro modulo.
4. Detectar e eliminar ciclos de dependencia.
5. Encapsular regra no modulo dono.
6. Orquestrar integracao por API ou eventos internos.
7. Escrever testes por modulo.
8. Refatorar monolito legado para fronteiras claras.
