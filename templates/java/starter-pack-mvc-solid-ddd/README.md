# Starter Pack Java (MVC + SOLID + DDD)

Pack para arquiteturas em camadas, com foco em separacao de responsabilidades e dominio explicito.

## Quando usar

- APIs web com fluxo de negocio mais linear.
- Times que precisam de estrutura clara e onboarding rapido.
- Projetos que ainda nao demandam complexidade assincrona pesada.

## Notas

- MVC e frequentemente implementado com Spring MVC em Java.
- Ainda assim, mantenha regras de negocio fora de controllers e detalhes de framework.
