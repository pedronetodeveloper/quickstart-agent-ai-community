# Checklist de Qualidade (MVC + SOLID + DDD)

- Controller sem regra de negocio?
- Caso de uso claro e coeso?
- Dominio com invariantes explicitas?
- DTOs desacoplados do modelo interno?
- Erros traduzidos corretamente na fronteira?
- Testes unitarios de dominio/aplicacao criados?
- Testes de integracao do fluxo principal criados?
