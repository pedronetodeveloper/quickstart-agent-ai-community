# Skills Prioritarias do Agente (MVC + SOLID + DDD)

1. Modelar entidades e value objects com invariantes claras.
2. Definir casos de uso na aplicacao com responsabilidade unica.
3. Estruturar controllers finos e sem regra de negocio.
4. Projetar contratos de repositorio por intencao de negocio.
5. Separar DTOs externos de modelos internos.
6. Centralizar tratamento de erros por fronteira.
7. Escrever testes unitarios de dominio e aplicacao.
8. Escrever testes de integracao para API e persistencia.
