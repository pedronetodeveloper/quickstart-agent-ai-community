# Skills — API em camadas

- Estruturar rotas/controllers finos e delegar para serviços.
- Modelagem de contratos HTTP com Zod ou validação equivalente.
- Design de serviços testáveis e desacoplados.
- Acessar banco ou APIs externas via `repositories`/`adapters`.
- Lidar com erros e códigos HTTP de forma consistente.
- Testes unitários de serviços e testes de integração de rotas.
