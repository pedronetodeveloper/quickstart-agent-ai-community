# Starter Pack JavaScript Node — Pacotes por domínio

Pack para projetos Node.js maiores e bem modularizados, com `src/` e pacotes organizados por contexto de negócio.

## Quando usar

- Monólito ou aplicação modular que cresce em escopo.
- Deseja evitar importações cruzadas e acoplamento entre features.
- Prefere clareza de fronteiras de domínio sem forçar microservices.

## O que não é

- Não é layout flat sem separação de pacotes.
- Não é arquitetura de microservices distribuídos; é modularização dentro de um único repositório.
