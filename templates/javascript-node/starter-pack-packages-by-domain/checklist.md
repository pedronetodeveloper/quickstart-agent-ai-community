# Checklist — Pacotes por domínio

- [ ] Cada domínio está em uma pasta clara sob `src/`.
- [ ] Imports entre domínios são explícitos e bem definidos.
- [ ] Não há ciclos de dependência entre pacotes.
- [ ] Utilitários comuns estão centralizados em `shared` ou `common`.
- [ ] Pacotes expõem apenas sua API pública necessária.
- [ ] Testes de cada domínio são colocados dentro do próprio pacote.
