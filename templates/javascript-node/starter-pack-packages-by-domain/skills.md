# Skills — Pacotes por domínio

- Definição de boundaries de domínio em `src/`.
- Exportação clara de APIs de pacote.
- Identificação e remoção de ciclos de importação.
- Uso de aliases e paths para reduzir imports relativos.
- Organização de testes dentro de cada pacote.
- Separação de código de domínio e infraestrutura.
