# Starter Pack JavaScript Node — Serverless Functions

Pack para aplicações Node.js focadas em funções serverless em nuvem: Vercel, AWS Lambda, Netlify, Cloudflare Workers e semelhantes.

## Quando usar

- Funções ou endpoints em ambiente serverless.
- Projetos com deploy em CDN / edge ou arquitetura FaaS.
- Eventos HTTP, Webhooks ou integrações orientadas a função.

## O que não é

- Não é aplicação stateful de longo prazo.
- Não é arquitetura de serviço persistente tradicional com sessão local.
