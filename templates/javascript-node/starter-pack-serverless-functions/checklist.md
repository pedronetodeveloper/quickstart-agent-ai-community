# Checklist — Serverless Functions

- [ ] Handler/função é leve e focada.
- [ ] Validação de entrada ocorre antes da lógica de negócio.
- [ ] Lógica de negócio está separada do runtime.
- [ ] Dependências de inicialização são mínimas.
- [ ] Erros são tratados e retornados de forma adequada.
- [ ] Possui testes locais ou mocks de runtime.
