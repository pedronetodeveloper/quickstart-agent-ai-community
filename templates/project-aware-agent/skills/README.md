# Skills Example Files

Esta pasta contém exemplos de arquivos de skills que mostram o formato desejado para um agente gerar skills específicas do projeto.

## Como usar

- Não considere estes arquivos como o conjunto final de skills.
- Eles servem apenas para demonstrar categorias, estruturas e estilo de escrita.
- O agente deve gerar novos arquivos de skills baseados nas necessidades reais do projeto.

## Categorias de exemplo

- `analysis.json`: análise de arquitetura, dependências e contexto.
- `refactor.json`: refatoração e melhoria de código.
- `testing.json`: geração e melhoria de testes.
- `documentation.json`: documentação e explicação de decisões.
- `quality.json`: qualidade, CI/CD e manutenção.
