# Starter Pack Python — Django monólito modular (apps)

Pack para o padrão mais comum em **Django**: projeto único com **vários `apps`**, cada um com modelos, views, serializers ou templates coesos.

## Quando usar

- Projeto Django (admin, ORM, migrations).
- Time quer fronteiras claras por domínio usando `INSTALLED_APPS`.
- Necessidade de evitar “God app” com todo o código acoplado.

## O que não é

- Não substitui a documentação oficial do Django; complementa com convenções para agentes de IA.
