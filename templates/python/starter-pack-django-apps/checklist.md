# Checklist — Django apps

- [ ] Feature vive no app com responsabilidade de negócio correta?
- [ ] Migrations geradas e revisadas (dados existentes considerados)?
- [ ] Views/viewsets finas com lógica complexa em serviço quando necessário?
- [ ] Serializers ou forms como borda de validação coerente?
- [ ] Permissões e autenticação explícitas no fluxo?
- [ ] Testes cobrindo happy path e pelo menos um caso de erro?
- [ ] Listagens sem N+1 óbvio?
