# Checklist — Pacotes por domínio

- [ ] Cada domínio tem pacote com nome de negócio claro?
- [ ] `src/` (ou convenção do projeto) respeitada?
- [ ] Sem ciclos de import novos?
- [ ] `shared/` (se existir) permanece pequeno e estável?
- [ ] API pública documentada ou explícita no `__init__.py`?
- [ ] Testes rodam com `pip install -e .` ou equivalente?
- [ ] `pyproject.toml` consistente com o layout real?
